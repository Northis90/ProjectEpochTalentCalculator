# ProjectEpochTalentCalculator
Addon for talent building

Install into your addons folder "Interface/AddOns/EpochTalents/"
All talents are like the ones from https://project-epoch.org/talents/?class=warrior
Save/Load slots per class
Import/Export (may have issues)
Link button will have a click link into chat that will show other players builds that can be shared and saved

Feel free to modify, will update/tweak if or when I have time

Enjoy!
